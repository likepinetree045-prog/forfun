    도움말 & 셋업 가이드

    최초 1회 셋업:

    1. https://developer.spotify.com/dashboard 에서 앱 생성 (또는 기존 앱 사용)
    2. 앱 Settings → Redirect URIs에 위 박스의 URL을 그대로 추가 → Save
    3. Client ID를 복사해 이 페이지의 "설정"에 입력 → 저장
    4. 아래 "로그인" 진행

    이 페이지는 PKCE OAuth를 사용해 Client Secret이 필요 없습니다. 토큰은 본인 브라우저(localStorage)에만 저장됩니다.
